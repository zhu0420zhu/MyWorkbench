# 验收用例（勾选式）

环境：Windows 10/11 x64；安装包或便携版 **0.1.0**。

图例：P0 必测 · P1 建议测

## A. 安装与启动

| ID | 步骤 | 期望 | 优先级 | 结果 |
|---|---|---|---|---|
| A1 | 安装 NSIS 或运行便携版 | 应用可启动，侧栏可见 | P0 | ☐ |
| A2 | 侧栏模块名称 | 含「文档处理」「写作」等；无「游戏UI设计」入口 | P0 | ☐ |
| A3 | 深浅主题切换 | 立即生效，布局不坏 | P0 | ☐ |
| A4 | 无边框窗口最小化/最大化/关闭 | 行为正常 | P0 | ☐ |

## B. AI 配置

| ID | 步骤 | 期望 | 优先级 | 结果 |
|---|---|---|---|---|
| B1 | 设置 → AI 模型 → 新建配置 | 可填名称/endpoint/Key/模型并保存 | P0 | ☐ |
| B2 | 测试连接 | 成功显示延迟或明确报错 | P0 | ☐ |
| B3 | 配置两套并「启用」切换 | 「当前」标记变化，调用走启用项 | P0 | ☐ |
| B4 | 快速预设（智谱/小米等） | 地址与模型自动填入 | P1 | ☐ |
| B5 | 数据文件 ai-config.json | 无明文 apiKey（仅 apiKeyEnc） | P0 | ☐ |

## C. 写作与工作流

| ID | 步骤 | 期望 | 优先级 | 结果 |
|---|---|---|---|---|
| C1 | 写作 → 新建作品（填书名/题材） | 创建成功，默认第一卷 | P0 | ☐ |
| C2 | 右栏灵感 → 工作流 | 自动挂载（玄幻→网文快写流） | P0 | ☐ |
| C3 | 运行步骤「开书三件套」 | 弹结果；需已配置 AI | P0 | ☐ |
| C4 | 勾选步骤完成 | 进度与「下一步」更新 | P0 | ☐ |
| C5 | 切换工作流（雪花等） | 可切换且提示 | P1 | ☐ |
| C6 | 对话区连续编辑 | 输入框不莫名跳动；会话不串作品 | P0 | ☐ |
| C7 | 选中聊天输入/正文右键 | 出 AI 菜单 | P0 | ☐ |

## D. 文档处理

| ID | 步骤 | 期望 | 优先级 | 结果 |
|---|---|---|---|---|
| D1 | 打开 .md | 预览/编辑/分屏可用 | P0 | ☐ |
| D2 | 打开带图 .docx | 图片显示、表格有边框 | P0 | ☐ |
| D3 | Word 视图改字 → 保存 | 可保存；docx 有 .bak 或明确提示 | P0 | ☐ |
| D4 | 编辑时连续输入 | 不自动跳到顶部 | P0 | ☐ |
| D5 | Ctrl+F / Ctrl+S / Ctrl+W | 查找/保存/关闭 | P0 | ☐ |
| D6 | 工具栏无「AI 右键」按钮 | 仅选中右键出菜单 | P0 | ☐ |
| D7 | 右键 AI → 润色 → 替换选中 | 结果写入正文或输入框 | P0 | ☐ |
| D8 | 打印 | 系统打印对话框 | P1 | ☐ |
