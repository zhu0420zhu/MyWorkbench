# 已知问题与路线图

## 已知 / 工程债

| 项 | 说明 | 影响 |
|---|---|---|
| electron-builder Windows rename EPERM | 本机 node_modules 已打补丁（先释放锁再 rename，失败则 copy）；`npm i` 可能还原 | 打包偶发失败 |
| 无自动更新 | 未接 electron-updater | 需手动换装新版本 |
| xlsx@0.18.5 | 旧版 SheetJS 有已知 CVE | 建议后续换 exceljs |
| 主窗口 sandbox/webview | 情报内嵌浏览器依赖 webviewTag | 安全加固需单独评估 |
| snake_case 残留 | 文件工具类型仍混用 Python 风格字段 | 可维护性 |
| 检索质量 | 知识库为倒排+计分，无向量/IDF | 复杂语义召回偏弱 |
| DOCX 复杂版式 | HTML 往返保存可能丢样式 | 导出 Word 后建议微调 |
| 统计为增量 | 数据看板从安装后累计 | 无历史迁移 |
