# 项目架构

## 技术栈

| 层 | 选型 |
|---|---|
| 桌面壳 | Electron 43 + electron-builder（NSIS / portable） |
| 构建 | electron-vite + Vite 7 + TypeScript 7 |
| UI | React 19 + Ant Design 5 |
| 图表 | ECharts 6 |
| 白板 | tldraw 5 |
| OCR | onnxruntime-web 1.16.3 + paddle-ocr-onnx（PP-OCRv4 + SLANet） |
| 文档转换 | Pandoc / LibreOffice（resources/tools，可选） |
| 热点源 | dailyhot-api |
| Markdown | marked + DOMPurify |

**依赖策略**：主进程偏「零原生存储依赖」（JSON/文件 + 可选 SQLite 表库）；渲染层打包进 `out/renderer`。

## 进程与通信

```
┌─────────────────────────────────────────────┐
│ Renderer (React)  window.api.*              │
│        ▲ contextBridge (preload)            │
│        ▼                                     │
│ Main (Electron)  ipcMain.handle(domain:action)│
│   存储：userData 纯文本 / kb / novel / tables│
└─────────────────────────────────────────────┘
```

- IPC 命名：`domain:action`（如 `novel:create-project`、`docs:pick`）
- 安全：`contextIsolation` + preload；webview 用于情报内嵌浏览
- AI：OpenAI 兼容 `chat/completions`（流式 + complete）；**多套配置**，Key 经 `safeStorage` 加密
- 异常：`installGlobalErrorHandlers` 写 `userData/logs/`

## 仓库结构（节选）

```
src/main/           主进程：窗口、IPC、业务存储
  ai.ts             AI 多配置 + chat/complete + 用量统计钩子
  usageStats.ts     模型/页面使用统计
  docsIpc.ts        文档打开/保存/DOCX 媒体内联/Pandoc
  novel/            长篇：作品、工作流、实体、伏笔、上下文
  knowledgeBase/    知识库流水线 + 数据资产 + # 引用解析
  searchIndex/      倒排检索 + 问答
  feed/ publish/    热点与多平台分发
  tools/            文件工具 + logger
src/preload/        window.api 类型与桥接
src/shared/types.ts 契约（AI/文档/工作流/统计等）
src/renderer/src/
  pages/            各模块页面（Writing、DocsViewer、TextTools、Settings…）
  components/       工作流、AI 右键菜单、壁纸层等
  utils/            textTools、ppocr、ioFormats
项目验收/           本文档目录
```

## 数据目录（默认 `%APPDATA%\lingmo-workbench\`）

| 路径 | 内容 |
|---|---|
| preferences.json | 主题/默认页/壁纸分区 |
| ai-config.json | **多套 AI 配置（v2，Key 加密）** |
| usage-stats.json | 数据看板统计 |
| notes/、boards/、novel/、kb/、tables/ | 模块数据 |
| logs/ | 主进程日志（按日） |
| wallpapers/ | 壁纸图片副本 |
| snapshots/ | 笔记/草稿版本 |

可自定义数据目录（设置 → 数据与存储，重启生效）。

## 页面导航

`navItems.tsx` 单点维护侧栏与窗口标题。  
`docs` = 文档处理；`gameui` 代码保留但导航已注释。

## 关键设计决策

1. **文件化存储**：数据可备份、可 Git、可手工修  
2. **工作流挂在作品 meta**：新建自动推荐 + 播种 Skill  
3. **文档 Word 模式**：Pandoc HTML + contentEditable（非受控，防跳动）；保存回 DOCX 留 `.bak`  
4. **壁纸分区**：titlebar / sider / content 可独立模式与图片  
5. **AI 右键**：body 级 contextmenu，覆盖多页面  
6. **本地 OCR**：WASM 离线，不上传图片  

## 开发与打包

```powershell
npm.cmd install
npm.cmd run typecheck   # node + web
npm.cmd run dev
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
npm.cmd run build:win   # → dist/
```

注意：本机 npm 用 `npm.cmd`；打包时勿占用 `dist/win-unpacked` 内 exe。
