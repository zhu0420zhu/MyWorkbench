| 依赖 | 说明 |
|---|---|
| Windows x64 | 必须 |

## 打包流程（开发者）

```powershell
# 退出正在运行的灵墨工作台，避免 EBUSY
Get-Process 灵墨工作台 -ErrorAction SilentlyContinue | Stop-Process -Force
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://npmmirror.com/mirrors/electron-builder-binaries/'
$env:NODE_OPTIONS = ''
npm.cmd run typecheck
node node_modules/electron-builder/out/cli/cli.js --win
```

产物目录：`dist/`。

**Windows 打包注意**：  
electron-builder 解压 `win-unpacked` 时可能 EPERM（锁文件）。若失败，清理：

```powershell
rmdir /s /q dist\win-unpacked
rmdir /s /q dist\win-unpacked.tmp
```
