## 快速验收路径（建议 15 分钟）

1. 安装或运行 `dist/灵墨工作台 Setup 0.1.0.exe`（或便携版）
2. 设置 → AI 模型：添加并「启用」至少一套 OpenAI 兼容配置 → 测试连接
3. 写作：新建长篇作品 → 右栏「工作流」应自动挂载 → 运行「开书三件套」
4. 文档处理：打开 `.docx` / `.md` → Word 视图编辑 → 保存 / 打印
5. 文本工具：粘贴多行文本 → 去重 / 全半角 / 词频
6. 设置 → 氛境壁纸：切换预设，观察标题栏/侧栏/内容区
7. 任意页面选中文字 → 右键 → AI（改写/润色等）
