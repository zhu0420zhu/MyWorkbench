# 功能清单（验收对照）

> 与侧边栏实际菜单一致（游戏UI设计入口已隐藏，代码保留）。

## 侧栏模块总览

| 模块 | 一句话 | 验收重点 |
|---|---|---|
| 自动工作台 | 快捷卡片 + 自动化 + AI 入口 | 卡片增删、命令流式输出 |
| 本地知识库 | 目录建索引 / 问答 / 数据资产 | 建索引、问答引用 |
| 文件工具 | 磁盘/目录/重复/监控 | 选目录、查重 |
| **文档处理** | 打开/编辑/Word/打印/AI 右键 | DOCX 图片表格、保存、打印 |
| **写作** | 短篇+长篇+工作流+AI 助手 | 新建作品自动挂工作流、编辑正文 |
| **文案** | 文案场景助手 | 可选中右键 AI |
| 笔记 | Markdown + 标签 + 快照 | 编辑、历史回滚、导出 |
| 便利贴 | 悬浮置顶 + 日历 | 桌面悬浮同步 |
| 文本工具 | 批处理 / 编码 / OCR / Diff | 分类工具条可用 |
| 数据整理 | 表/看板 + 导入导出 | CSV/Excel 导入 |
| 白板 | tldraw 画布 | 画笔/便签自动保存 |
| 情报中心 | 全网热点 + 分发 | 拉取热点、点击打开 |
| 数据分析 | 图表 + 筛选 + 结论 | 表/CSV 聚合 |
| 设置 | 存储/AI/个性化/看板 | 多套 AI、壁纸分区、数据看板 |

---

## 1. 自动工作台

- 快捷卡片：网址 / 命令，图标与颜色
- 自动化命令：运行、流式输出、停止、工作目录
- 内置案例教程（一键填入配置）
- AI 对话入口（记忆开关可导出/导入）

**验收点**：新建快捷方式 → 点击打开；自动化命令能跑通并看到输出。

## 2. 本地知识库

- 按目录建索引（文本 + 可选图片视觉描述）
- 问答（Chat with Files + 检索）
- 数据型资产（CSV/XLSX 登记，可聚合）
- 会话历史、偏好

**验收点**：选目录建索引 → 问答能引用文件名/片段。

## 3. 文件工具

- 磁盘容量/使用率
- 目录占用分析
- 重复文件（哈希）
- 目录监控事件流
- 手动选择路径

## 4. 文档处理

- 打开：MD / TXT / PDF / DOCX / HTML / JSON / CSV / 代码 / 图片
- **DOCX**：Pandoc 转 HTML，**内嵌图 base64**，表格样式
- **Word 视图**：B/I/U、H1/H2、列表、对齐、字号、颜色、字体、行距、缩进/引用、插表格、清除格式
- 保存 / 另存为 / 关闭（Ctrl+S / Ctrl+W）
- 查找替换、撤销/重做（文本类；Word 模式工具栏撤销）
- 打印；DOCX 保存回写（`.bak` 备份）；导出 Word/HTML
- **选中右键 → AI** 菜单（与写作/笔记共用）

**验收点**：打开带图 DOCX 不裂图；能改字并保存；右键 AI 出菜单。

## 5. 写作

- 短篇（角色库 + 对话）与长篇（作品/卷/章）同壳
- 长篇：章节树、正文编辑、大纲、实体、伏笔、灵感、一致性、成书导出
- **工作流自动挂载**（默认网文快写流，可切换雪花/三幕/英雄之旅/去AI味）
- AI 助手：# 挂载知识库、技能、MCP、插入本章
- 会话按作品隔离；快照回滚

**验收点**：新建「玄幻」作品 → 工作流面板出现 → 运行第 1 步。

## 6. 文案

- 文案对话 / 热点相关场景
- 支持全文选中后 **右键 AI**（与写作同一套动作）

## 7. 笔记

- Markdown 编辑/预览、Ctrl+S、标签、快照历史
- 导出 md/json；与知识库/成书衔接

## 8. 便利贴

- 5 色便签、桌面 alwaysOnTop 悬浮、任务日历

## 9. 文本工具

| 分类 | 功能 |
|---|---|
| 行处理 | 去重、重复统计、排序、反转行、去空行、去空白、行号、合并行、段落整理 |
| 转换 | 大小写、反转字符、全角↔半角、首字母拼音 |
| 清理 | 去中英标点、HTML→文本、去 Markdown、行尾空格、LF |
| 排版 | 引号、行前/后缀、批量符号（%index% 等） |
| 编码 | Base64/URL/JSON 格式化/HTML 转义 |
| 增强 | 词频 Top50、slug、详细统计 |
| 替换 | 正则替换、批量规则（查找\|替换） |
| 其他 | 关键词高亮、差异对比、翻译、**OCR 批量**（离线 WASM） |

**排版**：左侧分类导航 + 当前分类工具条 + 输入/输出双栏；打开文件；输出→输入。

## 10. 数据整理

- 自定义字段表 + 看板 + ECharts
- CSV/JSON/TSV/Excel 导入导出

## 11. 白板

- tldraw：选择、画笔、便签、连线等；自动保存

## 12. 情报中心

- 多平台热点聚合、去重、推送、分发队列、应用内浏览

## 13. 数据分析

- 数据表/CSV 图表、筛选维度、规则化结论

## 14. 设置

| 分区 | 内容 |
|---|---|
| 数据看板 | 模型调用/用量、模块内容量、页面访问；刷新/清空 |
| 数据与存储 | 数据目录、备份导入 |
| AI 模型 | **多套配置**：列表/启用/删除/测试；国内预设（智谱/小米 MiMo 等） |
| 个性化 | 主题色、**氛境壁纸**（全局+标题栏/侧栏/内容区独立、自定义色/图）、动效 |
| MCP 集成 | 外部工具服务器 |
| 快捷键 | Ctrl+K / Ctrl+N / Alt+1… |
| 存储格式 | 文件化数据说明 |

**分区卡片**：默认收起，点击展开，状态记忆。

## 全局能力

- 深浅主题、无边框窗口、独立窗口打开页面
- Ctrl+K 命令面板
- **AI 右键菜单**（写作/文案/笔记/文档处理）
- 氛境壁纸（分区可调）
- 使用统计（usage-stats.json）
